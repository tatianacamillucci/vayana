# Vayana

*Progetto di studio — sviluppato da autodidatta, non è un prodotto commerciale.*

## Il problema
Nei piccoli team progetti, attività e scadenze si disperdono tra email, chat e fogli di calcolo sparsi: nessuno ha il quadro completo di chi sta facendo cosa.

## La soluzione
Un'applicazione web che raccoglie in un unico spazio progetti, attività e persone: si assegnano i compiti, si segue l'avanzamento e ogni utente accede con il proprio profilo e vede ciò che gli compete.

## Cosa ho imparato
- Progettare un'applicazione completa: interfaccia (frontend), server (backend) e database
- Gestire account, accessi e permessi diversi per ogni persona
- Automatizzare controlli e rilasci del codice

## Strumenti
React, TypeScript, NestJS, PostgreSQL, GitHub Actions.
